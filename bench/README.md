# Snarta MoE Benchmark Tool

Автоматический бенчмарк для подбора оптимального параметра -ncmoe и измерения производительности моделей Mixture-of-Experts (MoE), таких как Gemma 4 26B-A4B.

Скрипт поочередно запускает llama-server с разными значениями -ncmoe, прогревает модель, выполняет серию контрольных замеров через API /v1/chat/completions, собирает метрики генерации и выводит сводную таблицу с лучшим результатом.

## Возможности

- Замер скорости генерации (eval tokens/sec) и времени префилла (prompt eval tokens/sec).
- Статистическая обработка: расчет среднего, минимума, максимума и стандартного отклонения по нескольким прогонам.
- Сравнение с базовым вариантом (baseline без флага -ncmoe) и расчет процента ускорения.
- Замер времени холодной загрузки модели (model load time) для каждого значения -ncmoe.
- Автоматический поиск исполняемого файла llama-server и модели .gguf в стандартных папках репозитория.
- Формирование отчетов в форматах Markdown и JSON в папке bench/reports.
- Готовая строка конфигурации для вставки в snarta.toml.
- Работает на стандартной библиотеке Python 3 без обязательных внешних зависимостей.

## Быстрый старт

Запуск из корня проекта на Windows:

```powershell
python bench/bench_ncmoe.py
```

Скрипт автоматически найдет установленный llama-server в папке runtime и первую найденную модель в папке models.

## Примеры запуска

### Тестирование Gemma 4 Q8_0 с диапазоном ncmoe от 2 до 26 с шагом 2

```powershell
python bench/bench_ncmoe.py `
  -s "target\release\runtime\b1370-rocm-gfx110X-x64\llama-server.exe" `
  -m "target\release\models\gemma-4-26B-A4B-it-ultra-uncensored-heretic-Q8_0.gguf" `
  --range 2 26 2 `
  --cooldown 4 `
  --runs 2 `
  --max-tokens 256
```

### Тонкая настройка вокруг оптимальной точки (шаг 1)

```powershell
python bench/bench_ncmoe.py `
  -m "models\gemma-4-26B-A4B-it-ultra-uncensored-heretic-Q3_K_L.gguf" `
  --range 2 6 1 `
  --runs 3 `
  --max-tokens 512
```

### Выборочные значения ncmoe через список

```powershell
python bench/bench_ncmoe.py `
  --ncmoe "none,4,12,18,24" `
  --cooldown 5
```

### Подробный вывод логов сервера в реальном времени

```powershell
python bench/bench_ncmoe.py --range 2 8 2 --verbose
```

## Основные параметры

- -s, --server: путь к llama-server.exe (если не указан, ищется автоматически).
- -m, --model: путь к файлу модели .gguf (если не указан, ищется автоматически).
- --range START STOP [STEP]: автоматическая генерация диапазона ncmoe от START до STOP с шагом STEP (например, --range 2 28 2).
- --ncmoe: список конкретных значений через запятую (например, "none,2,4,6,8,12,18,24").
- --mtp [FILE|auto|none]: подключение спекулятивного MTP драфт-слоя (-md <file> --spec-type draft-mtp). При значении auto или вызове без аргумента автоматически ищет mtp-*.gguf рядом с моделью.
- --no-baseline: исключить запуск baseline (без флага -ncmoe). По умолчанию baseline всегда замеряется первым для расчета ускорения.
- --cooldown: задержка в секундах после выгрузки модели перед следующим запуском (по умолчанию: 4.0 сек). Нужна для очистки VRAM драйвером ROCm/Windows.
- --pre-unload-delay: задержка в секундах перед завершением сервера для сброса сокетов и буферов (по умолчанию: 1.0 сек).
- -r, --runs: количество контрольных прогонов на каждую конфигурацию (по умолчанию: 2).
- --warmup: количество предварительных прогревочных прогонов (по умолчанию: 1).
- --max-tokens: максимальное количество токенов генерации на запрос (по умолчанию: 256).
- -c, --ctx: размер контекстного окна (по умолчанию: 32000).
- -ngl: количество слоев на GPU (по умолчанию: 99).
- -b, --batch: логический размер батча (по умолчанию: 2048).
- -ub, --ubatch: физический размер микробатча (по умолчанию: 512).
- --kv-type: квантование KV-кэша (по умолчанию: q8_0).
- --load-mode: режим загрузки весов, mlock или none (по умолчанию: mlock).
- --fa: flash attention, on или off (по умолчанию: on).
- --reasoning: флаг рассуждений, on или off (по умолчанию: on).
- --reasoning-effort: уровень усилий рассуждений (по умолчанию: xhigh).
- --host: адрес сервера (по умолчанию: 127.0.0.1).
- --port: TCP порт сервера (по умолчанию: 8089).
- --prompt: пользовательский текст запроса для бенчмарка.
- --extra-args: дополнительные параметры командной строки для передачи в llama-server.
- -o, --output-dir: папка для сохранения отчетов (по умолчанию: bench/reports).
- -v, --verbose: вывод всех строк лога llama-server в консоль.

## Результаты

По завершении теста скрипт выводит итоговую таблицу:

```text
+-----------------------+--------------+------------+---------------+----------+------------------+---------+
| Configuration         | Eval (t/s)   | Min..Max   | Prefill (t/s) | Load (s) | Speedup          | Status  |
+-----------------------+--------------+------------+---------------+----------+------------------+---------+
| baseline (no -ncmoe)  | 8.41 +/-0.12 | 8.29..8.53 | 612.4         | 16.2     | 1.00x (baseline) | OK      |
| -ncmoe 4              | 10.20 +/-0.15| 10.05..10.3| 615.1         | 16.1     | 1.21x (+21.3%)   | OK      |
| -ncmoe 12             | 15.38 +/-0.20| 15.18..15.5| 618.3         | 15.8     | 1.83x (+82.9%)   | OK      |
| -ncmoe 18             | 18.45 +/-0.10| 18.35..18.5| 620.0         | 15.6     | 2.19x (+119.4%)  | OK      |
| -ncmoe 24             | 22.95 +/-0.30| 22.65..23.2| 621.5         | 15.4     | 2.73x (+172.9%)  | WINNER  |
+-----------------------+--------------+------------+---------------+----------+------------------+---------+
```

Также в папку bench/reports сохраняются файлы:
- bench_<модель>_<дата_время>.md: отчет в формате Markdown.
- bench_<модель>_<дата_время>.json: сырые данные со всеми прогонами и метриками.

Полученное лучшее значение достаточно указать в файле snarta.toml:

```toml
[model_defaults]
extra_args = "-ncmoe 24"
```

# Snarta MMLU Intelligence Benchmark

Инструмент академического тестирования интеллекта и рассуждений моделей (Massive Multitask Language Understanding) для оценки деградации качества при переходе между квантами (Q4, Q5, Q6, Q8).

Скрипт проверяет точность ответов на вопросы с множественным выбором (A, B, C, D) по четырем основным дисциплинам: STEM, Humanities, Social Sciences, Other. Поддерживает автоматический подбор оптимального флага -ncmoe для каждого кванта, формирует отчеты в Markdown и JSON, а также строит интерактивный автономный HTML/SVG дашборд с графиками Парето (точность против скорости генерации).

## Быстрый старт MMLU

Быстрый замер на встроенном сбалансированном датасете (100 вопросов):

```powershell
python bench/bench_mmlu.py
```

Тестирование конкретной модели:

```powershell
python bench/bench_mmlu.py `
  -s "target\release\runtime\b1370-rocm-gfx110X-x64\llama-server.exe" `
  -m "target\release\models\gemma-4-26B-A4B-it-ultra-uncensored-heretic-Q5_K_M.gguf" `
  --ncmoe 10
```

Сравнительный тест всех квантов подряд с автоматическим выбором оптимального -ncmoe:

```powershell
python bench/bench_mmlu.py `
  --models "models\*Q4*.gguf,models\*Q5*.gguf,models\*Q6*.gguf,models\*Q8*.gguf" `
  --ncmoe auto `
  --cooldown 5
```

Тестирование против уже запущенного сервера llama-server:

```powershell
python bench/bench_mmlu.py --server-url "http://127.0.0.1:8089" --model-name "gemma-4-Q5_K_M"
```

Загрузка и запуск полного официального датасета MMLU (57 предметов):

```powershell
python bench/bench_mmlu.py --download-official --limit 500
```

Фильтрация по категориям или лимит на предмет:

```powershell
python bench/bench_mmlu.py --categories "STEM,Humanities" --limit-per-subject 5
```

## Основные параметры MMLU

- -s, --server: путь к llama-server.exe.
- -m, --model: путь к одной модели .gguf.
- --models: список моделей через запятую или glob-шаблон.
- --models-dir: папка для поиска всех моделей .gguf.
- --server-url: адрес уже запущенного сервера для тестирования без перезапуска.
- --dataset: путь к файлу датасета JSON или CSV (по умолчанию: bench/data/mmlu_sample.json).
- --download-official: скачать официальный архив Hendrycks data.tar (57 предметов).
- --categories: фильтр категорий через запятую (STEM, Humanities, Social Sciences, Other).
- --subjects: фильтр предметов через запятую (например, formal_logic,college_computer_science).
- --limit: ограничение общего числа вопросов.
- --limit-per-subject: ограничение числа вопросов на предмет.
- --ncmoe: значение -ncmoe или auto для автоподбора по кванту (Q4: 7, Q5: 10, Q6: 14, Q8: 17).
- --cooldown: пауза в секундах между моделями для сброса VRAM (по умолчанию: 5.0).
- --no-plots: отключить генерацию графиков и HTML дашборда.

## Результаты и графики

По итогам теста в папку bench/reports сохраняются:
- mmlu_<модель/сравнение>_<дата>.md: сводная таблица точности и разбивка по категориям.
- mmlu_<модель/сравнение>_<дата>.json: полные результаты с логом каждого вопроса.
- mmlu_<модель/сравнение>_<дата>_dashboard.html: интерактивный дашборд с графиками точности, диаграммами категорий и кривой Парето (открывается в любом браузере офлайн).
- mmlu_<модель/сравнение>_<дата>_chart.png: высококачественный график при установленном matplotlib.

# Snarta RuMMLU / MERA Russian Intelligence Benchmark

Русскоязычный академический бенчмарк на базе стандартов RuMMLU и MERA (Multimodal & Multitask Evaluation of Russian Accuracy) для оценки понимания русского языка, сложной грамматики, терминологии и специфических для РФ дисциплин.

Датасет содержит 120 выверенных вопросов с выбором одного правильного ответа (A, B, C, D) по пяти направлениям:
- STEM: высшая математика, физика, химия, биология, генетика, алгоритмы и теория информации (25 вопросов).
- Humanities: история России (от Древней Руси до Великой Отечественной войны), философия, силлогистика и формальная логика, юриспруденция РФ (Конституция, ГК РФ, УК РФ) (25 вопросов).
- Social Sciences: микро- и макроэкономика, социология, когнитивная психология, политология, менеджмент и маркетинг (25 вопросов).
- Russian Language & Culture: орфография, пунктуация в сложных предложениях, синтаксис, фразеология, классическая литература, искусство, зодчество и музыка (25 вопросов).
- IT Edge Cases: архитектура ядра Linux, сокеты и протоколы QUIC/HTTP3, уровни изоляции транзакций в СУБД, неблокирующая многопоточность, borrow checker в Rust, внутренности GIL CPython (20 вопросов).

Автоматический экстрактор ответов адаптирован под кириллические омоглифы (А, В, С, Д) и различные русскоязычные формулировки ответов модели.

### Запуск RuMMLU через CLI

Быстрый запуск на русскоязычном датасете:

```powershell
python bench/bench_mmlu.py --dataset rummlu
```

Сравнение нескольких моделей на русском языке:

```powershell
python bench/bench_mmlu.py `
  --dataset rummlu `
  --models "models\*heretic*.gguf,models\*multilingual*.gguf" `
  --ncmoe auto `
  --cooldown 5
```

Тестирование только категорий языка и права:

```powershell
python bench/bench_mmlu.py --dataset rummlu --categories "Russian Language & Culture,Humanities"
```

# Snarta Hardcore Stress Benchmark (Ceiling Breaker)

Специализированный стресс-тест из 100 сложных задач с подвохами, когнитивными ловушками и многошаговой дедукцией для преодоления эффекта насыщения (ceiling effect) и выявления реальной разницы между квантами (Q3_K_L, Q4_K_M, Q5_K_M, Q8_0):
- Multi-Step Math & Algorithms: пошаговое исполнение алгоритмов, модульная арифметика, рекуррентные соотношения, планарные графы, IEEE 754 float32 трюки (20 вопросов).
- Cognitive Traps & Paradoxes: задача Уэйсона, вариации Монти Холла, парадокс Симпсона, байесовское пренебрежение базовой ставкой, парадокс двух конвертов (20 вопросов).
- Low-Level Systems & Concurrency: модель памяти x86 TSO против слабоупорядоченной ARMv8, edge-triggered epoll starvation, TLB shootdown, ABA-проблема в lock-free стеках, spectre v1, Write Skew в Snapshot Isolation (20 вопросов).
- Formal Logic & Counterfactuals: первая теорема Геделя, миры Крипке в модальной логике S5, силлогизмы с ловушками нераспределенных терминов, контрфактические кондиционалы Льюиса (20 вопросов).
- Adversarial Linguistics & Russian Syntax: синтаксическая омонимия, смещение антецедента, пресуппозиции, ирреальные кондиционалы, деепричастные ловушки (20 вопросов).

Запуск через CLI:

```powershell
python bench/bench_mmlu.py --dataset hardcore --models "models\*Q3*.gguf,models\*Q4*.gguf,models\*Q5*.gguf" --ncmoe auto --cooldown 5
```

# Snarta Benchmark Runner TUI

Интерактивный терминальный интерфейс для запуска и контроля бенчмарков MMLU, RuMMLU, Hardcore Stress и MoE. Работает в Windows 11 (PowerShell, Windows Terminal) и Linux на стандартной библиотеке Python 3 без сторонних зависимостей.

## Возможности TUI

- Интерактивное меню с навигацией стрелками Up/Down, выбором моделей пробелом и клавишей a.
- Автоматическое сканирование моделей в папках models и target/release/models с исключением mmproj и clip.
- Автоматическое сканирование всех датасетов в папке bench/data: стандартные (Hardcore, RuMMLU, English MMLU) и любые пользовательские тесты JSON/CSV.
- Выбор датасета стрелками Left/Right в поле Dataset.
- Динамическая синхронизация категорий под выбранный датасет.
- Выбор режима тестирования: MMLU Intelligence, MoE Concurrency Sweep, Full Pareto Suite.
- Фильтрация категорий бенчмарка по отдельности или выбор All.
- Настройка параметров: ncmoe (auto или число), reasoning (off/on), max_tokens, размер контекста ctx.
- Экран живого исполнения с отображением текущего вопроса, категории, прогресса, точности и скорости генерации tokens/sec.
- Итоговый экран с таблицей метрик, статусами WINNER/OK и открытием сгенерированного HTML дашборда в браузере по клавише O.

## Запуск TUI

Интерактивный запуск:

```powershell
python bench/bench_tui.py
```

Запуск с предвыбором конкретного датасета:

```powershell
python bench/bench_tui.py --dataset snarta_it_test_chatgpt
```

Тестовый прогон с симуляцией без сервера:

```powershell
python bench/bench_tui.py --mock
```

# Пользовательские тесты и датасеты

Любые собственные наборы тестов в форматах JSON, JSONL или CSV можно добавлять в папку bench/data/. Они автоматически обнаруживаются парсером и появляются в списке выбора в TUI и CLI.

Формат JSON:
- Массив объектов или словарь с ключом questions, data или tests.
- Поля каждого вопроса: question (вопрос), choices (варианты ответов списком или словарем A, B, C, D), answer (буква A..D, кириллическая А..Г, индекс 0..3 или текст совпадения).
- Необязательные поля: subject (тема), category (категория, например IT Edge Cases, STEM, Humanities, Social Sciences). Если категория не указана, парсер вычисляет ее автоматически по ключевым словам.

Парсер устойчив к завершающим запятым, строчным комментариям вида // и неэкранированным управляющим символам.

Формат CSV:
- Таблица с колонками question, a, b, c, d, answer (с заголовками или без).

Запуск пользовательского теста через CLI:

```powershell
python bench/bench_mmlu.py --dataset snarta_it_test_chatgpt
python bench/bench_mmlu.py --dataset snarta_it_test_deepseek
```
