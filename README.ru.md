# Snarta (`snarta-llm-harness-gui`)

[English](README.md) | **Русский**

Нативный Rust-харнес и десктопный GUI-клиент для локальных LLM поверх `llama.cpp` (`llama-server`), спроектированный с прицелом на **минимальный расход VRAM и системной RAM**.

## Зачем это нужно

Большинство локальных GUI-лаунчеров и агентских оболочек работают поверх Electron, WebView или тяжёлых Python-рантаймов. Они расходуют сотни мегабайт и гигабайты оперативной и видеопамяти ещё до загрузки модели, а при увеличении контекстного окна приводят к тихому вытеснению весов и KV-кэша в общую память через PCIe, что резко замедляет генерацию.

**Snarta** убирает лишние прослойки, чтобы максимум физической памяти доставался самой модели и её контексту:

* **Нативный стек без браузерного движка.** Один компактный бинарник на Rust с GPU-рендерингом интерфейса (`gpui` / `gpui-kit`) — без Electron, Node.js и Python в основном рантайме.
* **Точный контроль VRAM и KV-кэша.** Чтение реальной физической видеопамяти на Windows через DXGI и PDH (`\GPU Adapter Memory(*)\Dedicated Usage`) вместо заниженных WMI-значений, оценка вместимости контекста (`fit`) с явным отображением пролива в shared RAM (`spill_mib`) и квантизацией KV-кэша (`q8_0` по умолчанию).
* **Освобождение памяти перед запуском (`prepare`).** Быстрое завершение фоновых процессов, занимающих VRAM и RAM (браузеры, оверлеи, мессенджеры), до старта тяжёлых моделей.
* **Поддержка MoE и больших контекстов.** Управление `-ncmoe` (оффлоад экспертов на CPU) и автоматическая калибровка производительности через встроенный набор бенчмарков.

## Возможности

* **Desktop GUI (`gpui`):** потоковый вывод, сворачиваемые блоки размышлений (`reasoning`), вставка изображений из буфера обмена и проводника для vision-моделей, управление персонами и сессиями.
* **Агентский цикл (`AgentEngine`):** встроенный tool-calling с карточками инструментов в интерфейсе (работа с ФС, `edit_file`, выполнение команд, локальный поиск, веб-поиск/скрейпинг, режим планирования, интерактивные вопросы пользователю) и защитой от зацикливания.
* **Управление рантаймом:** загрузка и переключение сборок `llama.cpp` (ROCm для AMD gfx110X и Vulkan), автонастройка аргументов запуска, передача `extra_args` и наследование `[model_defaults]` в `snarta.toml`.
* **Бенчмарки (`bench/`):** TUI-раннер, MMLU/стресс-прогоны и автоматический подбор `-ncmoe` (подробнее в [bench/README.md](bench/README.md)).

## Требования

* **Целевая ОС:** Windows x64 (основная платформа для GUI, DXGI/PDH-телеметрии и `llama-server.exe`).
* **Инструментарий:** Rust (`edition = "2024"`).

## Сборка

### На Windows (MSVC, рекомендуемый релиз)

```powershell
cargo build --release
```

Готовый бинарник будет находиться в `target\release\snarta.exe`.

### Кросс-компиляция / проверка с Linux (`mingw-w64`)

В `.cargo/config.toml` настроен линкер `x86_64-w64-mingw32-gcc` для таргета `x86_64-pc-windows-gnu`:

```bash
rustup target add x86_64-pc-windows-gnu
cargo check --target x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
```

### Тесты

```bash
cargo test
```

## Использование

Запуск без аргументов открывает графический интерфейс:

```powershell
snarta
```

Доступные CLI-подкоманды:

* `snarta doctor` — диагностика окружения, конфигурации и рантайма.
* `snarta prepare` — освобождение RAM/VRAM согласно `[prepare]` в `snarta.toml`.
* `snarta runtime ...` — управление установленными сборками `llama.cpp`.
* `snarta fit [model]` — расчёт вместимости контекста под текущую свободную VRAM.
* `snarta serve [model]` / `snarta stop` — запуск и остановка `llama-server`.
* `snarta bench [model]` — встроенный бенчмарк.
* `snarta path install` / `snarta path uninstall` — добавление/удаление каталога с `snarta.exe` в пользовательский `PATH`.

## Структура репозитория

* `src/main.rs` — точка входа и CLI-маршрутизация.
* `src/gui/` — интерфейс на `gpui` / `gpui-kit`, карточки инструментов, модальные окна и состояние.
* `src/chat/` — клиент `llama-server`, промпты, `AgentEngine`, управление сессиями и `Workspace`.
* `src/server/` — `ServerController`, формирование аргументов запуска и расчёт `fit`.
* `src/tools/` — реестр и реализация агентских инструментов.
* `src/gpu.rs`, `src/sysmon/` — DXGI/PDH-телеметрия и очистка фоновых процессов.
* `src/runtime/` — установка и обновление сборок `llama.cpp`.
* `bench/` — Python-инструменты для замеров скорости и качества моделей.
* `docs/JOURNAL.md` — журнал архитектурных решений и технических заметок.
