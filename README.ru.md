# Snarta (`snarta-llm-harness-gui`)

[English](README.md) | **Русский**

Snarta это нативный десктопный GUI-клиент и агентский харнес на Rust для `llama.cpp` (`llama-server`). Приложение экономит память, чтобы веса модели и KV-кэш помещались в физическую видеопамять без вытеснения в ОЗУ.

## Зачем нужен этот клиент

Оболочки на Electron, WebView или Python занимают сотни мегабайт RAM и VRAM еще до запуска модели. Когда видеопамяти впритык, часть слоев или KV-кэша уходит в общую память через PCIe, и скорость генерации резко падает.

Snarta работает как один бинарник на Rust без браузерного движка:

- **Нативный интерфейс на GPUI**: Окна рендерятся напрямую через GPU на базе `gpui` и `gpui-component`.
- **Точный замер VRAM на Windows**: Программа читает реальную занятую видеопамять через DXGI и счетчики PDH (`\GPU Adapter Memory(*)\Dedicated Usage`) вместо урезанного лимита WMI. По умолчанию включено квантование KV-кэша `q8_0`.
- **Очистка памяти перед запуском (`Prepare`)**: Модальное окно показывает фоновые программы с расходом RAM и VRAM (браузеры, оверлеи, мессенджеры) и закрывает выбранные процессы.
- **Тонкая настройка MoE и контекста**: Поддерживается выгрузка экспертов `-ncmoe` на CPU и индивидуальные профили моделей в `snarta.toml`.

## Возможности

- **Чат со стримингом и рассуждениями**: Потоковый вывод текста, сворачиваемые блоки размышлений, вставка картинок из буфера обмена и через проводник, история сессий и профили персон (`personas/*.md`).
- **Живой ASCII-портрет персоны**: В боковой панели и на стартовом экране отображается лицо персоны с учетом пола (`gender = "female"` или `"male"` в заголовке файла персоны). Выражение лица меняется по ходу работы агента или через прямой вызов инструмента `set_emotion` самой моделью.
- **Встроенные инструменты агента**: Карточки в чате для чтения и правки файлов, команд терминала, поиска по файлам и в сети, скрейпинга, списков задач, вопросов пользователю (`ask_user`) и смены эмоций.
- **Менеджер движка**: В настройках можно скачивать и переключать сборки `llama.cpp` (ROCm для AMD gfx110X и Vulkan).
- **Бенчмарки в `bench/`**: Python-скрипты и TUI-раннер для замера скорости, подбора `-ncmoe` и прогонов MMLU, RuMMLU и стресс-тестов. Подробности в [bench/README.md](bench/README.md).

## Требования

- Целевая ОС: Windows x64 (нужна для DXGI/PDH-телеметрии, очистки процессов и запуска `llama-server.exe`).
- Инструментарий: Rust (`edition = "2024"`).

## Сборка и проверка

### Windows (MSVC)

```powershell
cargo build --release
```

Готовый файл появится по пути `target\release\snarta.exe`.

### Кросс-проверка с Linux (`mingw-w64`)

Файл `.cargo/config.toml` уже настраивает линкер `x86_64-w64-mingw32-gcc` для цели `x86_64-pc-windows-gnu`:

```bash
rustup target add x86_64-pc-windows-gnu
cargo check --target x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
```

### Тесты

```bash
cargo test
```

## Запуск

Запускайте графическое приложение напрямую:

```powershell
snarta.exe
```

Настройки, диагностика, установка сборок `llama.cpp`, выбор персоны и очистка памяти открываются прямо из окна программы. Рабочие папки (`models/`, `runtime/`, `logs/`, `personas/`, `life/`) и файл `snarta.toml` создаются рядом с бинарником.

## Структура проекта

- `src/main.rs`: Точка входа графического приложения.
- `src/gui/`: Интерфейс на GPUI, тема, иконки Lucide, ASCII-аватар, модальные окна и карточки инструментов.
- `src/chat/`: Клиент `llama-server`, сборка системного промпта, цикл агента `AgentEngine`, сессии и `Workspace`.
- `src/server/`: Управление процессом `ServerController`, сборка флагов запуска и расчет вместимости контекста.
- `src/tools/`: Реестр и реализация инструментов агента.
- `src/gpu.rs`, `src/sysmon/`: Мониторинг VRAM через DXGI/PDH и закрытие фоновых процессов.
- `src/runtime/`: Загрузка и переключение сборок `llama.cpp`.
- `bench/`: Python-скрипты для подбора `-ncmoe` и оценки моделей.
- `docs/JOURNAL.md`: Технические заметки и принятые архитектурные решения.
